# 읽기 화면 구성

| 요소 | 상태 및 동작 |
| --- | --- |
| 상단 도구 | 파일과 폴더 선택, 테마 전환. 선택 중 열기 버튼 비활성화 |
| 파일 탐색 | 폴더 접기·펼치기, 현재 파일 표시, 빈 목록과 긴 이름 처리 |
| 본문 | 메타데이터, Markdown 렌더링, 로딩·빈 화면·오류. 표와 코드만 가로 스크롤 |
| 검색 | 입력, 대소문자, 개수, 이전·다음, Esc 종료. 렌더링된 제목·본문·코드·표의 텍스트 검색 |
| 목차 | 제목 단계에 따른 들여쓰기, 현재 위치 표시, 항목 선택 시 제목으로 초점 이동 |
| 좁은 화면 | 본문을 유지하고 도구 막대에서 탐색 또는 목차를 연다 |
| 상태 표시줄 | 읽기 전용, UTF-8 및 로딩 상태 표시 |
