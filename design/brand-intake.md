# BI 반영 기록

| 항목 | 근거 | 적용 |
| --- | --- | --- |
| 심볼 | 제공된 `Logo.png` | `src/assets/mark.png`에 원본 보관. 설치 아이콘은 투명 여백을 조정하고 비율을 유지한 크기별 복제본 사용 |
| 워드마크 | 제공된 `BI 타이포그래피.png` | `src/assets/wordmark.png`에 원본 보관. 상단 브랜드와 예제 이미지에 사용 |
| 색상 | 제공된 심볼의 파랑·인디고 | 화면 적용용 근사색을 잠정 사용. 공식 색상값은 제공되지 않음 |
| 글꼴 | 이미지 내 워드마크 | UI 및 코드에 시스템 글꼴 사용. 브랜드 글꼴 및 웹 라이선스 정보는 제공되지 않음 |
| 다크 테마 | 별도 에셋과 규칙 미제공 | 잠정 UI 팔레트와 흰색 로고 바탕을 적용 |

앱이 참조하는 값의 원본은 `src/tokens.css`다. `design-tokens.json`에는 BI 원시값과 역할의 매핑을 기록한다.
