# Markdown Viewer 사용 가이드

로컬 Markdown 문서를 읽고 탐색할 수 있는 작업 공간입니다. 파일 하나를 열거나, 연결된 문서와 이미지를 함께 보려면 폴더를 선택하세요.

> 문서는 이 기기에서만 처리됩니다. 열람 중 원본 파일이나 이미지가 수정되지 않습니다.

## 빠른 시작

1. **파일 열기**를 눌러 `.md` 또는 `.markdown` 파일을 선택합니다.
2. 여러 문서를 함께 읽으려면 **폴더 열기**를 사용하세요.
3. 오른쪽 **목차**에서 제목을 선택하면 해당 위치로 이동합니다.

## 문서 안에서 찾기

상단 검색창에 찾을 단어를 입력하세요. Enter로 다음 결과, Shift+Enter로 이전 결과로 이동합니다. `Aa`를 켜면 영문 대소문자를 구분합니다.

| 작업 | 단축키 |
| :--- | :--- |
| 문서 내 검색 | Ctrl / ⌘ + F |
| 다음 검색 결과 | Enter |
| 이전 검색 결과 | Shift + Enter |
| 검색 종료 | Esc |

## 연결된 문서 읽기

폴더를 열면 문서 간 상대 링크를 따라갈 수 있습니다. [Markdown 표현 예제](가이드/표현-예제.md)에서 코드, 표, 체크리스트를 확인해 보세요. [파일과 개인정보](가이드/파일과-개인정보.md)에는 지원 형식과 접근 범위를 정리했습니다.
