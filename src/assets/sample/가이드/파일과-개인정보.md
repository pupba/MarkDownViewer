# 파일과 개인정보

Markdown Viewer는 사용자가 열어 준 파일을 읽습니다. 본문과 이미지는 기기에서 처리합니다.

## 파일 형식

UTF-8 또는 UTF-8 BOM으로 저장된 `.md`, `.markdown`을 열 수 있습니다. 문서와 이미지의 파일당 크기 제한은 20 MiB입니다.

## 폴더 및 이미지

폴더 안의 Markdown 문서로 이동할 수 있습니다. PNG, JPEG, GIF, WebP 이미지는 선택 범위 안에서 표시합니다.

## 원본 다시 읽기

상단 새로고침 버튼으로 원본을 다시 읽으세요. 파일이나 폴더의 현재 내용을 가져오기 위해 브라우저가 다시 선택하도록 요청할 수 있습니다.
