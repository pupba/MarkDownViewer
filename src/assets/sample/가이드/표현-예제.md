# Markdown 표현 예제

기술 문서에서 자주 만나는 Markdown 표현입니다. [사용 가이드](../시작하기.md#빠른-시작)로 돌아갈 수 있습니다.

## 체크리스트

- [x] 문서 열기
- [x] 목차로 이동
- [ ] 문서 안에서 검색

## 코드 블록

```typescript
const extensions = ['.md', '.markdown'];

function isMarkdown(name: string): boolean {
  return extensions.some(extension => name.toLowerCase().endsWith(extension));
}
```
